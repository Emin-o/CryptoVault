# 🔐 CryptoVault - Dijital Şifre Kasa Sistemi

CryptoVault, Java ile geliştirilmiş konsol tabanlı bir güvenlik ve Sezar Şifreleme (Caesar Cipher) simülasyonudur.

## 🚀 Özellikler
- **PIN Güvenliği:** 3 kez üst üste hatalı girişte sistemi otomatik kilitler.
- **Sezar Şifreleme:** Karakter tabanlı ASCII kaydırma yöntemiyle metinleri şifreler ve çözer.
- **Canlı İşlem Sayacı:** Oturum boyunca yapılan şifreleme ve çözme işlemlerini loglar.
- **Sonsuz Menü Akışı:** Kullanıcı çıkış yapana kadar kesintisiz işlem imkanı sunar.

## 🛠️ Kullanılan Teknolojiler & Konular
- Java Core (`Scanner`, `Switch-Case`, `While/For Loops`)
- ASCII Karakter Aritmetiği ve Type Casting
- `Try-With-Resources` ile Güvenli Kaynak Yönetimi
